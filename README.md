# yukisaitoo.github.io

Personal site, built with [Vite](https://vite.dev) + React + TypeScript and styled with SCSS (CSS Modules). Pages are prerendered to static HTML at build time, then React takes over in the browser.

## Development

```bash
npm install
npm run dev           # http://localhost:5173
npm run build         # type-check, client + SSR builds, prerender to dist/
npm run preview       # serve dist/ locally
```
